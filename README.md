# JOJO Juice — Fresh Start

New React + Vite public site, based on Mr. Spring & Mrs. Fresh as layout reference while retaining JOJO brand identity and photographs. Pages: Home, Story, Menu, Outlet, Contact. No prior Cloudflare D1, Worker, CMS, admin or API. `npm install && npm run dev` for development; `npm run build` for production. Old project is available via previous git commits.
